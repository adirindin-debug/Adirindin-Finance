# Adirindin Finance

Production-ready Next.js App Router landing site for Adirindin Finance — markets research and finance commentary for Australian investors.

Domains: adirindinfinance.com.au and adirindinfinance.com

## Stack

- Next.js App Router, TypeScript, Tailwind CSS v4
- Shared layout with nav and footer
- SEO metadata and Open Graph

## Pages

- Home (/)
- Approach (/approach)
- Research (/research)
- Dashboard (/dashboard) — coming soon placeholder
- Contact (/contact)

## Local development

Install dependencies with the Node package manager, then start the Next.js development server. Open http://localhost:3000

## Production build

Use the package scripts named build and start.

## Deploy on Vercel

Import the repository into Vercel (Next.js preset). Add domains adirindinfinance.com.au and adirindinfinance.com. Point DNS as instructed. No env vars required for these marketing pages.

## Content policy

No invented market stats, fake testimonials, or fabricated performance claims.
